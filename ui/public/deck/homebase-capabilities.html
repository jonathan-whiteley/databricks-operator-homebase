Capability 01 · Genie

Ask your store anything, in plain language

A manager types a question the way they'd ask a shift lead. Genie translates it into a query over governed tables and answers with the number, the why, and the next move.

01
Natural language → governed answer
No SQL, no report-building. Questions resolve against trusted, permissioned data.
02
Always shows its source
Every answer cites the table it came from — like main.iot.fridge_telemetry — so it's trusted, not a black box.
03
Built for operators, not analysts
Prep, labor, stockouts, lapsing members — the daily questions, answered in seconds.

Capability 02 · Lakebase

Decisions that write straight back to the store

Insight only counts when it turns into action. Every approval, purchase order, service booking and guest reply commits instantly to Lakebase — the operational database that runs alongside the analytics.

01
A transactional store, not a batch job
Lakebase is a low-latency operational database — actions persist the moment they're taken.
02
One governed surface
Your lakehouse stays in sync, so Genie delivers performant analytical answers in seconds.
03
Every action is attributed
Approvals, orders and replies all land in Lakebase — auditable, reversible, real.
